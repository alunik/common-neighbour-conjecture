# The three Fi22 cases

This directory computes the three Fi22 rows in Table 1 of Lee--Popiel:

| point stabiliser | module |
| --- | --- |
| `3.Fi22` | `GF(4)^27` |
| `3.Fi22` | `GF(2)^54` |
| `3.Fi22.2` | `GF(2)^54` |

Put `H = 3.Fi22.2` and let `K = 3.Fi22` be its subgroup of index two.
The programs use the standard ATLAS representations supplied by GAP's
AtlasRep package.

The calculation has four parts.

1. GAP constructs the prime-order eigenspaces for `K`.  Exact centraliser
   actions and the C++ orbit program reduce these to 5,363 vectors.
2. GAP constructs the fixed spaces and centraliser actions for the three
   classes of outer involutions.  Their C++ orbits give another 743 vectors.
   These two lists meet every nonzero nonregular `H`-orbit.
3. Starting with one vector whose `H`-stabiliser is checked directly in GAP,
   the C++ programs find a regular-plus-candidate decomposition of every one
   of the 6,106 target vectors.  Equivariant colour refinement in the
   3,510-point Fischer action gives a small subgroup containing the stabiliser
   of each second summand.
4. GAP enumerates that subgroup, lifts each element through the normal group
   of order three, and checks directly that the second summand has trivial
   stabiliser.

All intermediate files are generated by these programs and are ignored by
Git.  In particular, the large `2A` orbit list is recomputed by
`enumerate_inner_orbits.cpp`; it is not supplied as an input file.

## Running on CREATE

The calculation requires GAP with AtlasRep, a C++20 compiler and Slurm.  From
the repository root, run

```bash
sporadic/large/fi22/run_create.sh
```

Export `GAP_BIN` before running if `gap` is not on `PATH`.  The driver submits
the exports in parallel and then orders the orbit, search and stabiliser jobs
with Slurm dependencies.  The final job prints

```text
5,363 inner targets and 743 outer targets were considered.
Each of the 6,106 nonregular target representatives is a sum of two
vectors with trivial stabiliser in 3.Fi22.2.

Together with the immediate decompositions for zero and for regular
targets, this gives R_H + R_H = V for H = 3.Fi22.2 on GF(2)^54.
The same equality holds for 3.Fi22 on GF(2)^54 and, through restriction
of scalars, for 3.Fi22 on GF(4)^27.
```
