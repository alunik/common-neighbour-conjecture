# Common-neighbour conjecture

This repository contains the computational code accompanying our work on the
common-neighbour conjecture for Saxl graphs.

The repository is intentionally small and source-focused.  The first material
included is the collection of computations for affine groups with almost
quasisimple sporadic point stabilisers.

## Contents

- [`sporadic/`](sporadic/): computations for the ten cases in Table 1 of
  Lee--Popiel.

More code will be added once we have decided which calculations from the paper
should be included.
